AP1 – Welcome Message


For this task I made a C++ program that welcomes the user and asks a question to the user. The end goal of this program was to help me learn the basics of programming and become more confident with things for example variables, input and output.

How program runs

When the C++ program starts it shows a message on the screen. Then the program asks the user a few questions and stores the answers in variables. Afterwards the program displays the information back to the user. It can also perform calculations if needed.

Software Used

I used the software program Visual Studio Code to write the C++ program and the terminal to run and test it. I then used GitHub to save the code and upload screenshots as evidence of the program.

How It Works

The C++ program starts in the function. I used the library so the program could display messages and receive user input.

- cout is used to show messages.

- cin is used to get input, from the user.

- Variables are used to store information.

- Operators can be used for calculations.

Steps

1. Start the C++ program.

2. Show a message on the screen.

3. Ask the user questions.

4. Store the answers in variables.

5. Do any calculations that are needed.

6. Display the results to the user.

7. End the C++ program.

Testing

I tested the C++ program times to make sure everything worked properly. I checked that the messages appeared correctly and that the user could enter information without any issues. If I found any mistakes I fixed them. I tested the C++ program again.
